# Fortune Pro Record

Screen recorder with camera overlay. Works fully offline once installed.

## Install as a laptop app (offline)
1. Open the live site once while online in Chrome or Edge:
   https://twealthdigital.github.io/fortune-pro-record/
2. Click the install icon in the address bar (or menu > Install app).
3. Done. It now opens from your Start menu / Dock and works with no internet.

## Download the files instead
Click the green **Code** button > **Download ZIP**, or:
`git clone https://github.com/twealthdigital/fortune-pro-record.git`

To run locally: `python -m http.server 8000` in the folder, then open http://localhost:8000

## Drawing tools + camera bubble extension
Download: https://twealthdigital.github.io/fortune-pro-record/fortune-cam-extension.zip
Pen, arrow, circle, box, colors, notes (white/black), and your camera bubble on every Chrome tab. See `extension/README.md`.

## Extension folder (manual)
See the `extension` folder (Chrome > chrome://extensions > Developer mode > Load unpacked).

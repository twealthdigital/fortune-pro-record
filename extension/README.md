# Fortune Cam Bubble

Puts your camera bubble on every Chrome tab so it shows up when you screen record.

## Install
1. Open chrome://extensions
2. Turn on Developer mode (top right)
3. Click Load unpacked and pick this extension folder
4. Allow the camera on the page that opens

## Use
- Click the extension icon in the toolbar to turn the bubble on or off
- Drag it anywhere, drag the orange dot to resize
- Hover it to switch circle or square, mirror, or close
- Position, size and shape are shared across all tabs

## Good to know
- It shows on normal websites. Chrome blocks extensions on chrome:// pages and the Web Store.
- It lives inside Chrome tabs. For other apps outside the browser, use the pop out camera in the recorder.
- Tabs that were already open need a refresh once after installing.

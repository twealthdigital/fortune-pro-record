# Fortune Cam Bubble + Annotation Tools

Puts your camera bubble and on-screen drawing tools on every Chrome tab, so they show up when you screen record.

## Install
1. Download and unzip `fortune-cam-extension.zip` (or use the `extension` folder)
2. Open chrome://extensions and turn on Developer mode (top right)
3. Click Load unpacked and pick the unzipped folder
4. Allow the camera on the page that opens

## Update
Replace the folder contents with the new files, then click the reload icon on the extension card in chrome://extensions. Refresh your open tabs.

## Use
Click the extension icon in the toolbar and switch on Camera bubble and/or Annotation tools.
Shortcut for the tools: Alt+Shift+A (change it at chrome://extensions/shortcuts).

### Annotation toolbar
- Pointer: use the page normally. Esc also returns to it
- Pen, Arrow, Circle, Box: pick one, then drag on the screen
- Colors: tap a swatch or the round picker for any color
- Thickness: cycle small / medium / large
- Note: opens a note on screen. Type in it, drag it by its top bar, resize from the corner, A- / A+ for text size, half-circle button switches white or black
- Fade: drawings disappear by themselves after about 3 seconds
- Undo (Ctrl+Z), Clear, and X to hide the tools. Drag the toolbar by its dotted handle

## Good to know
- Works on normal websites. Chrome blocks extensions on chrome:// pages and the Web Store
- To see the tools in your recording, record a Chrome tab, a Chrome window, or the entire screen with Chrome visible
- Drawings stay on the page you drew on and clear when you refresh it
